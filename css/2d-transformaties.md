# 2D Transformaties

## Leerdoelen

Na dit hoofdstuk kan je:

- Elementen verplaatsen met `translate()`
- Elementen schalen met `scale()`
- Elementen roteren met `rotate()`
- Het draaipunt van een transformatie aanpassen met `transform-origin`
