# Display

## Leerdoelen

Na dit hoofdstuk kan je:

- Het verschil uitleggen tussen blokelementen en inline-elementen
- Het weergavetype van een element aanpassen met de `display`-eigenschap (`block`, `inline`, `inline-block`, `none`)
- Het verschil toelichten tussen een element verbergen met `display: none` en `visibility: hidden`
- De juiste display-waarde kiezen voor lay-outelementen
