# CSS Variabelen

## Leerdoelen

Na dit hoofdstuk kan je:

- Het nut en de voordelen van CSS Custom Properties (variabelen) toelichten
- CSS-variabelen globaal declareren in de `:root`-pseudoklasse
- Variabelen toepassen en hergebruiken met de `var()`-functie
- Een terugvalwaarde (fallback) opgeven in de `var()`-functie
- Lokale variabelen overschrijven binnen een specifieke selector
- Een eenvoudig kleurenthema opbouwen en aanpassen met behulp van variabelen
