# 3D Transformaties

## Leerdoelen

Na dit hoofdstuk kan je:

- Diepte toevoegen met perspectief via `perspective`
- Elementen transformeren in drie dimensies (`rotateX()`, `rotateY()`, `translateZ()`)
- Het 3D-ruimtelijke gedrag van kindelementen bewaren met `transform-style: preserve-3d`
- De achterkant van een geroteerd element al dan niet tonen met `backface-visibility`
