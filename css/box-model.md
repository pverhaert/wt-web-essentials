# Box Model & Randen

## Leerdoelen

Na dit hoofdstuk kan je:

- Het CSS box model beschrijven (content, padding, border, margin)
- Binnenruimte en buitenruimte instellen met `padding` en `margin`
- Randen en stijlen toekennen met `border` en afgeronde hoeken maken met `border-radius`
- Diepte en schaduwen toevoegen met `box-shadow`
- De totale breedte en hoogte van een element berekenen
- Het verschil uitleggen tussen `box-sizing: content-box` en `box-sizing: border-box`
