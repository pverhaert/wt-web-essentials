# Kleuren

## Leerdoelen

Na dit hoofdstuk kan je:

- Verschillende kleursystemen gebruiken in CSS (kleurnamen, hex, RGB, HSL)
- Transparantie toepassen met de alfawaarde (RGBA, HSLA of 8-cijferige hex)
- Voldoende contrast garanderen tussen voorgrond en achtergrond voor toegankelijkheid
- Pseudo-klassen zoals `:hover`, `:active` en `:focus` gebruiken voor interactieve stijlen
