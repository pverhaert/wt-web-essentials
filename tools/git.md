# Git Basics

## Leerdoelen

Na dit hoofdstuk kan je:

- Uitleggen wat versiebeheer is en waarom het nuttig is
- Een lokale Git-repository aanmaken
- Bestanden toevoegen en vastleggen met `git add` en `git commit`
- De basisbewerkingen uitvoeren: `init`, `status`, `log`, `push`, `pull`
- Een remote repository verbinden via GitHub of GitLab
